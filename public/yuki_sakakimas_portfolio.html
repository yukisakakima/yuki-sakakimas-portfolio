Yuki Sakakima's Portfolio

Project

個人用、ポートフォリオサイト。
コンセプトは、初代IBMパソコンが好きだったこともあり、そのようなデザインをイメージした、ポートフォリオサイトを制作。
また、グラフィックに初代IBMパソコンのコンセプトを崩さない為、当時のスペックで可能なグラフィックとして幾何学模様を採用。

    link. vercel


Period: 2022.12 ~ 2023.01

Technology Stack: HTML CSS JavaScript Node.js

Goal

  •  - サイトの視認性の高さを確保、及びUIを意識したサイトを制作する。
  •  - 必要な機能が漏れ無くダブり無く存在する。
  •  - ユーザーの目を引くようなデザインにする。

Design Strategy

❍ Design style

1981年に発売された初代IBMをイメージしたデザインをベースに幾何学模様をグラフィックとして掛け合わせたデザイン。


❍ Color

Black, Green(rgb(13, 203, 69)), Yellow, Gray, Orange(rgb(241, 134, 8)), White


❍ Structure



❍ Fonts

フォントはサンセリフで統一しております。


❍ Logo

ロゴはサイトマップと私の名前の頭文字を合わせたイメージでデザイン。
